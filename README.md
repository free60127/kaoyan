# 研途 · 学科英语备考台

面向东北师范大学学科英语考研的个人学习网站。四科导航已建立；当前 333 教育综合接入四本《27KC 333 应试解析》章节、闪卡与 2024—2026 年真题练习。

闪卡库按四本书逐章逐节覆盖（2027 版，共约 1780 张）：每章先框架卡、后知识点卡；知识点卡由四本分册完整 OCR 文本逐章编写并校对（保留 PDF 页码出处，含书中考频标注），生成与校验脚本在工作区 `flashcards-src/`，不入库。数据文件为 `lib/knowledge-cards.json`。

网站提供章节学习、间隔复习闪卡、真题练习、费曼复述、语音转文字，以及 DeepSeek 生成学习计划、模拟题和复述反馈。DeepSeek API Key 由使用者在浏览器中输入，只保存在当前浏览器会话，请求直接发送给 DeepSeek；仓库和构建产物中没有密钥。学习进度保存在该浏览器的本地存储中。

## 本地运行

需要 Node.js 22 及以上。

```sh
npm ci
npm run dev
```

`npm run build` 生成静态文件到 `dist/`。推送 `main` 后，GitHub Actions 自动发布到 [GitHub Pages](https://free60127.github.io/kaoyan/)。

四本应试解析 PDF、完整 OCR 缓存和扫描页没有放入公开仓库。AI 生成的题目明确标记为模拟题，真题练习保留年份与来源信息。
