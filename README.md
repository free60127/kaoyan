# 研途 · 学科英语备考台

面向东北师范大学学科英语考研的个人学习网站。333 教育综合接入四本《27KC 333 应试解析》章节、闪卡与 2024—2026 年真题练习；825 英语专业基础接入语言学、英美文学两本书的章节、小节、909 张笔记闪卡，以及 2010—2026 年真题索引。政治已接入五科章节与考点闪卡；英语二资料区仍为占位。

闪卡库按四本书逐章逐节覆盖（2027 版，共约 1780 张）：每章先框架卡、后知识点卡；知识点卡由四本分册完整 OCR 文本逐章编写并校对（保留 PDF 页码出处，含书中考频标注），生成与校验脚本在工作区 `flashcards-src/`，不入库。数据文件为 `lib/knowledge-cards.json`。

网站提供章节学习、间隔复习闪卡、真题练习、费曼复述、中文或英文语音转文字，以及 DeepSeek 学习计划、模拟题和复述反馈。825 的历年题按章节归档为真题卡，也可按书目与年份练习；128 条 `practiceReady` 记录可文字作答，74 条索引记录只供浏览并显示资料限制。答案和解析来自题目记录注明的资料，其中非官方、回忆版与无参考答案题会明确标示；文字答案不做自动判分。AI 模拟题、参考思路和复述评分不是历年真题或标准答案。

DeepSeek API Key 由使用者在浏览器中输入，只保存在当前浏览器会话的 `sessionStorage`，请求直接发送给 DeepSeek；仓库和构建产物中没有密钥。学习进度保存在该浏览器的本地存储中；333、825、政治使用各自的 `yantu-srs-v1-科目` 复习记录与章节标记，旧版 `yantu-reviews` 记录会按需迁移。学习位置、费曼草稿和 825 真题作答自动保存，模拟卷设置、完整试卷与作答也自动保存。

## PDF 备份与答案复制

侧栏“备份与导出”适用于全部科目，也可从已生成的模拟卷打开。点击“导出 PDF 备份”下载可阅读的学习记录、完整模拟卷与作答，并内含恢复数据；中文字体仅在导出时按需加载。备份保留每日新卡配额、学习与复习范围、未来到期时间、章节完成标记、学习位置、费曼草稿、825 真题作答及模拟卷设置和作答。DeepSeek 密钥不包含在备份中。

在另一浏览器选择该 PDF，会先显示导出时间、科目记录数量与将替换的数据；确认前不会修改本地记录。仅本站生成的备份 PDF 可恢复，普通试卷 PDF 不可导入，文件上限 32 MiB。确认导入会替换备份中包含的整份记录，不合并；缺少的记录保持原状，成功后立即刷新。建议先导出当前记录再导入旧备份。本地保存出错或 AI 请求未完成时暂不可导出、导入。

费曼复述、825 真题文字作答、333 真题选择以及模拟卷逐题练习和整卷预览均可复制自己的当前答案；复制保留原文与换行，选择题含所选字母和选项。剪贴板不可用时会选中答案并提示按 Ctrl+C / ⌘C 手动复制。

学习数据先保存在当前浏览器；本站已预置公开的 Supabase 连接配置，侧栏“云同步”登录同一邮箱账号后，电脑和手机会自动同步学习记录。自行部署时可在高级连接设置中更换项目；公开 Publishable key 不包含服务端管理权限，访问控制仍由 Auth 与 RLS 负责。未登录时可自行传递 PDF 备份。草稿或个人笔记并发修改会保留双方内容；超过文字或样式上限时显示一个完整分支，双方原稿仍可从同步面板导出。其他冲突、账号隔离和发布验收见 [同步协议](docs/sync-v3.md)。

从侧栏切换科目会先进入“今日概览”，书目、章节、小节与草稿仍保留。应用内导航支持浏览器返回/前进；从搜索打开卡片可返回原搜索结果。首次进入空复习队列可把当前章加入学习并开始，或先自由浏览。开放题手动标记只表示待复习，不累计错误次数。

## 本地运行

需要 Node.js 22 及以上。

```sh
npm ci
npm run dev
```

`npm run build` 会运行 TypeScript 检查并生成静态文件到 `dist/`。本地开发预览运行 `npm run dev`；生产构建可运行 `npm run preview`。825 的书籍和真题 JSON 在进入 825 后按需加载，不计入 333 初始数据包。推送 `main` 后，GitHub Actions 自动发布到 [GitHub Pages](https://free60127.github.io/kaoyan/)。

四本应试解析 PDF、完整 OCR 缓存和扫描页没有放入公开仓库。AI 生成题目明确标记为模拟题，真题练习保留年份、题型、来源状态、PDF 文件与页码；可用范围受仓库 JSON 中记录的来源限制约束。
